# Validation of the Allen–Cahn model against the literature

Consolidated, reproducible validation campaign for the two Allen–Cahn
implementations in the local OOFEM build:

1. **parabolic** Allen–Cahn with dynamic boundary condition (bulk + first-order
   dynamic surface), benchmarked against **Okumura 2021, Ch. 4,
   *Computation example 2*** ([O1]);
2. **hyperbolic** inertial Allen–Cahn, benchmarked against the **exact bounded
   traveling wave of Nizovtseva–Galenko–Alexandrov 2016, eq. (29)** ([N1]).

Main report: [`validation/comparison_report.md`](validation/comparison_report.md).
The two main figures (PNG + PDF):
[`figures/figure_1_parabolic.png`](figures/figure_1_parabolic.png),
[`figures/figure_2_hyperbolic.png`](figures/figure_2_hyperbolic.png).

## How to rerun everything

From the **repository root** (`/home/marco/Documents/Work/oofem-SOFFA`):

```bash
# --- Benchmark 1: parabolic with dynamic boundary condition ---
python3 doc/stvowu_validation/validation_allen_cahn/parabolic/scripts/run_okumura_example2.py
python3 doc/stvowu_validation/validation_allen_cahn/parabolic/scripts/postprocess_okumura.py

python3 doc/stvowu_validation/validation_allen_cahn/parabolic/scripts/run_okumura_refinement.py
python3 doc/stvowu_validation/validation_allen_cahn/parabolic/scripts/postprocess_okumura_refinement.py

python3 doc/stvowu_validation/validation_allen_cahn/parabolic/scripts/make_figure1.py

# --- Benchmark 2: hyperbolic exact traveling wave ---
python3 doc/stvowu_validation/validation_allen_cahn/hyperbolic/scripts/check_exact_residual.py
python3 doc/stvowu_validation/validation_allen_cahn/hyperbolic/scripts/run_nizovtseva.py
python3 doc/stvowu_validation/validation_allen_cahn/hyperbolic/scripts/postprocess_nizovtseva.py
python3 doc/stvowu_validation/validation_allen_cahn/hyperbolic/scripts/make_figure2.py
```

The `run_*` scripts (re)generate the `.in` inputs into `input/`, invoke
`build/debug_magneto/oofem`, write the OOFEM log into `logs/` and the raw
exports into `results/`. The `postprocess_*` scripts read **only** the raw
exports (VTU files) and regenerate the CSVs above, metric by metric, with no
filtering, interpolation or substitution of raw data. Approximate wall time
in the debug build: ~1 min per parabolic run (n = 400 ~ 4 min), ~1 min per
hyperbolic mesh.

## Headline results (full detail in `validation/comparison_report.md`)

- **Parabolic:** total energy 77.4205 → 2.219·10⁻⁶ over 700 steps, monotone
  non-increasing at every step (max increment −9.70·10⁻⁸); agreement with the
  digitized Fig. 4.4 curve (0.01 ≤ t ≤ 0.4, axis 0–90): RMSE 0.9881, MAE
  0.8804, max |ΔE| 1.8323; spatial convergence order 2.07/2.32 (RMS, t = 0.3)
  on nested meshes n = 50/100/200/400. **Validated within the declared
  tolerances**, with the declared caveat that the literature reference is a
  digitized figure and the paper's scheme (finite differences) differs from
  OOFEM's (Q1, backward Euler).
- **Hyperbolic:** RMS vs the exact wave at T = 0.2: 2.918·10⁻⁵ / 7.323·10⁻⁶ /
  1.862·10⁻⁶ (n = 80/160/320), max 1.158·10⁻⁴ / 2.889·10⁻⁵ / 7.190·10⁻⁶;
  spatial convergence order 1.99/1.98 (RMS), 2.00/2.01 (max); interface
  position error 3.03·10⁻⁵, relative speed error 9.85·10⁻⁵ at n = 320.
  **Validated within the declared tolerances for the inertial bulk model. The
  dynamic boundary condition is NOT exercised and NOT validated in this
  test** — no available reference provides a solution for the coupled
  inertial-bulk/dynamic-surface model; this is stated explicitly in the
  report, the executive table and the Figure 2 title.

## Known limitations (declared in the report, §12)

- the parabolic literature reference is a digitized figure (raster
  uncertainty not separately quantified);
- OOFEM exports field values with 6 significant digits (C++ default stream
  precision in `vtkxmlexportmodule.C`); below ~5·10⁻⁶ (O(1) fields) mesh
  differences are export quantization and no convergence order is assigned;
- the 2D strip validates the 1D behavior exactly (verified: zero transverse
  variation), not the full 2D tangential Laplace–Beltrami operator;
- hyperbolic domain truncation to [−12, 12]: wave tails at T are ~10⁻⁵;
- no time-refinement study was run (Δt = 10⁻³ fixed; reported orders are
  spatial only);
- runs use the local debug build.
